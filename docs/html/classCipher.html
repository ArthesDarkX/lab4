Подробное описание

Класс для шифрования методом маршрутной перестановки

В классе ключ устанавливается в конструкторе. Для зашифрования используется метод encrypt. Для расшифрования используется метод decrypt.

Проверяет строку на соответствие правилам

Проверяет, что строка:

  • не является пустой;
  • не содержит цифр;
  • не содержит строчных букв; Строка не должна содержать строчных букв.
    Аргументы
    [in]stringвведённая строка.
    Исключения
    Cipher_errorЕсли строка пустая, в тексте присутствуют числа или строчные буквы.
    Проверяет строку на соответствие правилам: Строка не должна быть пустой. Строка не должна содержать чисел. Строка не должна содержать строчных букв.
    Аргументы
    [in]stringвведённая строка.
    Исключения
    Cipher_errorЕсли строка пустая, в тексте присутствуют числа или строчные буквы.
