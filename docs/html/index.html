Описание проекта

Программа предназначена для шифрования и расшифрования текстовых сообщений методом маршрутной перестановки.

Ограничения ввода

  • Ключ шифрования должен быть положительным числом.
  • Текст не должен быть пустым.
  • Текст не должен содержать цифр.
  • Текст не должен содержать строчных букв.

Структура проекта

lab4/
|-- Doxyfile
|-- README.md
|-- Makefile
|-- include/
| -- cipher.h
|-- src/
| |-- cipher.cpp
| |-- main.cpp
|-- tests/
| |-- unittest.cpp
|-- docs/
|-- html/
| |-- index.html
|-- latex/
|-- Makefile
|-- refman.tex

Назначение каталогов

  • include/ — заголовочные файлы проекта.
  • src/ — исходные файлы кода проекта.
  • tests/ — файлы модульных тестов.
  • docs/ — документация проекта.

Запуск программы

Для запуска программы необходимо:

  1. Клонировать git-репозиторий:
    git clone https://github.com/ArthesDarkX/lab4
  2. Выполнить команду:
    make
  3. Запустить программу
    ./cipher

Для запуска тестов необходимо выполнить команду:

make test

После тесты запустятся автоматически.

Для тестов используется стороняя библиотека UnitTest++

Генерация документации

Для создания документации необходимо выполнить команду

doxygen Doxyfile

После завершения генерации будет создан каталог docs.

HTML-документация будет расположена в каталоге:

docs/html

Для просмотра HTML-документации необходимо открыть файл index.html в браузере.

Чтобы просмотреть документацию в формате PDF необходимо перейти по пути:

docs/latex

и выполнить команду:

make

Для просмотра PDF-документации необходимо открыть файл refman.pdf.
